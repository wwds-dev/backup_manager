## backup_manager app
- PySide6 desktop app, **v2 complete** (2026-08-17). One scrollable dashboard of cards
  (not tabs) plus a menu-bar icon; launches maximized. Everything the v2 roadmap named is
  built: Google Drive + Dropbox quota via OAuth, the Google Photos Takeout helper, the Time
  Machine trigger (`tmutil startbackup`), the menu-bar companion, and PyInstaller packaging.
- Honest boundary: it does NOT reconfigure iCloud/Google/Dropbox/Proton sync engines
  (no API, iCloud sealed). It fully manages the rsync backup we own and monitors/links
  the rest.
- Open work is **v3 or blocked**, tracked in `backup_manager/SUGGESTIONS.md` — restore
  helper, S3/B2 as a second destination, email/webhook on failure; verification spot-check
  (needs the Drive API) and a quota trend chart (needs SQLite + a chart lib); and Developer
  ID code signing, which needs a paid Apple account and cannot be done in code. Read
  SUGGESTIONS.md before proposing features for this app — most obvious ones are already done.
